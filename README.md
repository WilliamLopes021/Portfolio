# Portfólio

## Como rodar este projeto

Este projeto foi criado usando **React + Vite**, então o processo é simples e rápido.

---

### Pré-requisitos

Antes de começar, verifique se você tem instalado:

- **Node.js** (versão 18 ou superior)
- **npm** ou **yarn**

Para conferir:

```bash
node -v
npm -v
```

### 1. Clonar Repositório

```bash
git clone https://github.com/DinoPimenteiro/Portfolio.git

# Entre na pasta do projeto
cd Portfolio
```

### 2. Instalar as dependências

Usando `npm`:

```bash
npm install
```

Usando `yarn`:

```bash
yarn install
```

### 3. Rodar o projeto

```bash
npm run dev

# com yarn

yarn dev
```

### Finalização

Seguindo todos os passos o vite iniciará um servidor local na URL informada no terminal.
Normalmente em: `http://localhost:5173`
